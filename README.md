# TaskMate — Student Task & Assignment Manager

## 1. Project Overview

**TaskMate** is a web-based task and assignment management system designed to help students organize their academic work in one place.

Students can create assignments, set deadlines, assign priorities, track their progress, and mark tasks as completed. A simple dashboard provides an overview of pending and completed assignments.

## 2. Problem It Solves

Students often have multiple assignments, projects, tests, and academic deadlines to manage simultaneously. Using separate notes, messaging apps, or paper-based reminders can make it difficult to keep track of upcoming work.

TaskMate provides a centralized platform where students can record and monitor their academic tasks, helping them stay organized and avoid missing deadlines.

## 4. Vision Statement

> **To provide students with a simple and centralized platform that makes organizing, prioritizing, and tracking academic tasks easier and more effective.**

## 5. Key Features / Goals

### Key Features

- Student login
- Dashboard displaying task information
- Create new assignments/tasks
- Add subject and description
- Set deadlines
- Set task priority
- View pending and completed tasks
- Mark tasks as completed
- Edit and delete tasks
- Filter tasks by status or priority
- View basic task statistics

### Project Goals

- Make academic task management simple.
- Reduce the chances of missed deadlines.
- Provide students with a clear view of their workload.
- Allow students to prioritize important tasks.
- Provide an easy-to-use interface.

## 6. Success Metrics

The project will be considered successful if:

- Students can create and manage tasks successfully.
- Users can easily identify upcoming and overdue assignments.
- Tasks can be completed and their status updated correctly.
- The application works successfully on localhost.
- The application can be built and run using Docker.
- The main application features work without errors.

## 7. Assumptions

- Users have access to a web browser.
- Users have basic familiarity with web applications.
- Each student manages their own academic tasks.
- Internet connectivity is available when using the deployed version.
- The initial version is intended primarily for individual students.

## 8. Constraints

- The project is developed within a limited academic project timeframe.
- The initial version will focus on core task-management functionality.
- The application will use a simple database structure.
- Development and testing will initially be performed locally.
- The project will use free or freely available development tools where possible.
- Advanced features such as real-time collaboration and complex notifications are outside the initial scope.
